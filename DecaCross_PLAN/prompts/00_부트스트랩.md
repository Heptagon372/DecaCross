## 프롬프트

```
이 저장소는 "데카크로스(DecaCross)" — 마인크래프트 서버 구축 통합 플랫폼이다.
지금은 문서만 있다. Kotlin 모노레포 뼈대를 만들어줘.

먼저 읽어라:
- CLAUDE.md (불변식, 모듈 소유권, 코딩 규칙)
- docs/00_스택결정_Kotlin.md (왜 Kotlin인지, 데몬/UI 분리 구조)
- docs/03_구현명세_v2.md §0 (확정 스택), §1 (레포 전체 트리)

작업:

1. 루트 설정
   - settings.gradle.kts (아래 모듈 전부 include)
   - build.gradle.kts (공통 플러그인/컴파일 옵션)
   - gradle/libs.versions.toml  ★ 모든 버전은 여기 한 곳
   - gradle wrapper (Gradle 9.x)
   - .editorconfig, ktlint 또는 detekt

2. core 모듈 (KMP, 타겟은 jvm 만 우선. js 는 Phase 2)
   - core:pubgrub-kt
   - core:compat-engine
   - core:dcx
   - core:logparse
   - core:jvm-analysis   (JVM 전용, KMP 아님)
   ★ core/* 는 explicit API mode 를 켜라. 공개 API 를 실수로 넓히지 않게.

3. app 모듈 (전부 Kotlin/JVM)
   - app:daemon        Ktor Server embedded, main 함수만
   - app:launcher-ui   Compose Multiplatform Desktop, 빈 창 하나
   - app:cli           인자 파싱만 (clikt 또는 kotlinx-cli)
   - app:collector     Ktor Client, main 만

4. verifier 모듈 (Kotlin/JVM)

5. web/ — Next.js 16 App Router + TypeScript strict + Tailwind
   ★ Gradle 밖이다. pnpm 으로 따로 관리.

6. infra/supabase/migrations/ 디렉터리 (.gitkeep)

7. CI: .github/workflows/ci.yml
   - ./gradlew build
   - ./gradlew ktlintCheck (또는 detekt)
   - pnpm -C web lint && pnpm -C web build

제약:
- 의존성 버전은 docs/03_구현명세_v2.md §0 표의 major/minor 만 지키고,
  patch 는 지금 시점 최신 안정 버전으로 잡아 libs.versions.toml 에 기록해라.
  내가 적은 숫자를 그대로 박지 마라.
- Compose Multiplatform 과 Kotlin 의 버전 호환표를 먼저 확인해라.
  둘은 짝이 맞아야 한다. 추측하지 말고 공식 호환성 문서를 봐라.
- 구현은 전부 TODO() / 빈 함수. 이 단계 목표는 "빌드가 통과하는 뼈대"다.
- JVM target 은 25.

끝나면 실행해서 결과를 보여줘:
  ./gradlew build
  ./gradlew ktlintCheck
  pnpm -C web build
```
